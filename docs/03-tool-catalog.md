# 03. 도구 카탈로그

우선순위 표기: **✅** = 구현 완료, **⏸** = 보류(범위 확정 필요), **P0** = MVP 필수, **P1** = 1차 확장, **P2** = 이후 추가

## 카테고리 정의

| ID           | 이름          | 아이콘        | 설명                        |
| ------------ | ------------- | ------------- | --------------------------- |
| `calculator` | 계산기        | calculator    | 일반·공학·비율 계산         |
| `unit`       | 단위 변환     | ruler         | 길이·무게·온도·용량 등 변환 |
| `finance`    | 금융 · 부동산 | banknote      | 이자·대출·세금·급여         |
| `math`       | 수학 · 공식   | sigma         | 공식 모음, 진법, 통계       |
| `datetime`   | 날짜 · 시간   | calendar-days | D-Day, 나이, 시간대         |
| `health`     | 건강 · 생활   | heart-pulse   | BMI, 칼로리, 요금           |
| `text`       | 텍스트 · 개발 | code          | 인코딩, 포맷, 변환          |
| `random`     | 랜덤 · 추첨   | dices         | 로또, 사다리타기, 뽑기      |

## 3. 금융 · 부동산 `finance`

> 모든 도구에 "참고용 계산이며 실제 금융기관 산정과 다를 수 있음" 고지와 **기준 일자**를 표기한다.

| 우선 | 도구 ID           | 이름                | 핵심 입력 → 출력                                                                            |
| ---- | ----------------- | ------------------- | ------------------------------------------------------------------------------------------- |
| P0   | `interest`        | 이자 계산기         | 원금·이율·기간·복리주기 → 단리/복리 이자, 세후(15.4%) 수령액, 연도별 표                     |
| P0   | `loan-repayment`  | 대출 상환 계산기    | 대출금·금리·기간·방식(원리금균등/원금균등/만기일시) → 월 상환액, 총이자, 회차별 상환 스케줄 |
| P0   | `loan-limit`      | 대출 한도 계산기    | 연소득·기존부채·주택가격·금리·기간 → DSR/DTI/LTV 기준 한도, 최종 한도(최솟값)               |
| ✅   | `savings`         | 예금 · 적금 계산기  | 월납입/예치금·이율·기간·단복리 → 만기 수령액, 세후 이자, 실효 연수익률                      |
| ✅   | `vat`             | 부가세 계산기       | 공급가↔합계금액 상호 변환, 세액 (역산 시 차액으로 확정해 합계 보존)                         |
| P1   | `salary`          | 연봉 실수령액       | 연봉·부양가족·비과세 → 4대보험·소득세 공제 후 월 실수령액                                   |
| P1   | `prepayment`      | 중도상환 시뮬레이터 | 상환 중 목돈 투입 시 총이자·기간 절감 비교                                                  |
| P2   | `exchange`        | 환율 변환           | 통화쌍·금액 → 환산액 (외부 API, 실패 시 수동 입력) `requiresNetwork`                        |
| P2   | `jeonse-wolse`    | 전월세 전환         | 보증금·월세·전환율 상호 계산                                                                |
| ✅   | `acquisition-tax` | 취득세 계산기       | 주택가격·주택수·면적 → 취득세·지방교육세·농어촌특별세, 다주택 중과 반영                     |
| ✅   | `brokerage-fee`   | 중개수수료 계산기   | 매매·임대차 법정 중개보수 상한. 월세는 환산보증금으로 구간 판정                             |
| ⏸    | `capital-gains`   | 양도소득세 계산기   | 범위 확정 필요 (장기보유특별공제·1세대1주택 비과세·다주택 중과)                             |
| P2   | `severance`       | 퇴직금 계산         | 입퇴사일·최근 3개월 급여 → 평균임금 기준 퇴직금                                             |
| P2   | `compound-goal`   | 목표금액 역산       | 목표액·기간·수익률 → 필요 월 적립액                                                         |

## MVP(P0) 확정 목록 — 12개

1. `calculator` 일반 계산기
2. `percentage` 퍼센트 계산기
3. `unit-length` 길이 변환
4. `unit-weight` 무게 변환
5. `unit-temperature` 온도 변환
6. `unit-area` 면적 변환 (평↔㎡)
7. `interest` 이자 계산기
8. `loan-repayment` 대출 상환 계산기
9. `loan-limit` 대출 한도 계산기
10. `date-diff` 날짜 계산기
11. `age` 만 나이 계산기
12. `bmi` BMI 계산기

여기에 `formula-reference`(수학 공식 모음)와 `char-count`(글자수 세기)를 더해
**8개 카테고리가 전부 최소 1개 도구를 갖는 상태**로 1차 배포한다. (총 14개)

## 도구 선정 기준 (앞으로 추가할 때)

1. **내가 최근 6개월 안에 검색해서 쓴 적이 있는가** — 없으면 후순위
2. 클라이언트 계산만으로 완결되는가 (외부 API 의존 최소화)
3. 입력 3~5개 이내로 유의미한 결과가 나오는가
4. 기존 도구의 옵션으로 흡수하는 게 낫지 않은가 (도구 수 인플레 방지)
